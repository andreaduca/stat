Toy EC-ElGamal on secp256k1

Part 1 defined key generation — a private key d and a public key Q = dG — but an elliptic curve alone does not encrypt anything. To encrypt a message we complete the scheme with EC-ElGamal, the standard public-key encryption on the same group: Q encrypts, d decrypts, and a fresh nonce k randomises each message. We keep the textbook form, not the hybrid one real systems use, because it makes the comparison with Caesar exact: both add a mask in a group. The curve is the real secp256k1; only the range of d is toy.
